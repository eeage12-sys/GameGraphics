DAY 09 - Particle System Basics

1) Merge this package's Assets folder into your existing GameGraphics project.
2) Wait for Unity import/compile to finish.
3) Run: Tools > DAY09 > Finalize Hit Spark Demo
4) Open Assets/Scenes/DAY09_ParticleBasics.unity if it is not already open.
5) Press Play. FX_HitSpark_Test emits once on awake.
6) To replay without restarting, use Tools > DAY09 > Play Hit Spark.

Generated/used assets:
- Assets/DAY09_Particle/HitSpark_Soft.png
- Assets/DAY09_Particle/DAY09_HitSpark.shader
- Assets/Materials/Mat_HitSpark.mat (generated by Finalize)
- Assets/Scenes/DAY09_ParticleBasics.unity (generated by Finalize)

Key settings follow DAY09:
- Looping off
- Short lifetime and duration
- Rate over Time = 0
- One Burst
- Cone/Sphere shapes
- Color over Lifetime fades alpha to 0
- Size over Lifetime shrinks particles
- Simulation Space = World
