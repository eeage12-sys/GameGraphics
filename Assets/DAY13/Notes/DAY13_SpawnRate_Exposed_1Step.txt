DAY13 SpawnRate Exposed Property - 정확히 이 1단계만 직접
============================================================

이유:
DAY12에서 사용한 VFX Graph 내부 Editor API는 Unity 6.6 버전 차이 때문에
여러 차례 컴파일/그래프 손상 문제가 발생했습니다.
DAY13에서는 이미 정상 완성된 DAY12 그래프를 보호하기 위해
VFX Graph 내부 노드를 비공개 API로 자동 삽입하지 않습니다.

실습 원문 그대로:
1. Assets/DAY12/VFX/VFX_GpuSpark.vfx 더블클릭
2. 왼쪽 Blackboard의 + 클릭
3. Float 선택
4. 이름: SpawnRate
5. 기본값: 80
6. Exposed 체크 ON
7. Blackboard의 SpawnRate를 Graph Area로 드래그
8. Spawn Context의 Constant Spawn Rate 블록에서 Rate 입력을 찾기
9. SpawnRate 노드의 출력 점 -> Rate 입력 점으로 선 연결
10. Ctrl + S

확인:
- Scene의 Visual Effect Inspector에 SpawnRate가 보이면 성공
- Tools > DAY13 FULL > 3 - Validate DAY13
- PASS SpawnRate Float Exposed Property가 나오면 완료

Play:
- 숫자 1 -> SpawnRate 20
- 숫자 2 -> SpawnRate 200
- 화면 왼쪽 상단 Overlay에서 SpawnRate와 Alive Particles 비교
